## Selected projects

### [Log Incident Analyzer](https://github.com/destinesia7187/log-incident-analyzer-vol1)

An offline investigation tool for application and nginx logs, built around a SOC L1 workflow.

- Normalizes events, applies eight configurable detectors, and links related alerts into investigation cases.
- Connects findings to source evidence and reports missing telemetry, alternative explanations, and next checks.
- Produces HTML, Markdown, and JSON reports with SQLite storage; includes reproducible evaluation scenarios and documented limitations.

**Python · SQLite · Log analysis · Detection engineering**

### [Digital Evidence Verification](https://github.com/destinesia7187/digital-evidence-verification)

My diploma research project at Astana IT University: image and video analysis using EfficientNet-B4, with GradCAM visualizations and metadata inspection.

- Combines model predictions, frame analysis, and metadata findings in a Flask interface.
- Generates PDF reports with digital signatures for report integrity verification.
- Documents the prototype's research scope and model setup requirements.

**Python · PyTorch · Flask · Explainable AI**

### [SSH Brute Force Detector](https://github.com/destinesia7187/ssh-brute-force-detector)

A Python CLI that identifies bursts of failed SSH logins from the same source IP within a configurable time window.

- Supports IPv4, IPv6, and two documented authentication log formats.
- Exports JSON evidence and maps the detection to MITRE ATT&CK T1110.001.
- Includes synthetic sample logs, unit tests, and a GitHub Actions test workflow.

**Python standard library · Authentication logs · MITRE ATT&CK**
